# Meta Prompts

Meta prompts are reusable prompts that help create, improve, or organize other development artifacts such as agent instructions, repository standards, workflows, documentation references, and project-specific AI environments.

## Available Prompts

| Prompt | Purpose |
|---|---|
| `bootstrap-project-ai-development-environment.md` | Inspects a repository and creates or updates project-specific AI-agent instructions, focused documentation, skills, and development environment rules. |
