# Engineering Playbook

A personal software engineering reference repository for building better, cleaner, safer, and more maintainable software.

This repository contains my notes, prompts, workflows, templates, AI-agent guidelines, software engineering principles, and blog drafts.

## Main Topics

- AI-assisted software development
- Developer productivity
- Clean architecture
- Maintainable code
- Secure software development
- Testing and quality engineering
- Repository standards
- AI-agent workflows
- Technical writing

## Repository Structure

| Folder | Purpose |
|---|---|
| `principles/` | Core engineering principles and beliefs |
| `prompts/` | Reusable prompts for AI-assisted development |
| `agent-guidelines/` | Guidelines for coding agents and AI assistants |
| `workflows/` | Step-by-step engineering workflows |
| `templates/` | Reusable document and process templates |
| `checklists/` | Practical checklists for development and review |
| `blog/` | Blog ideas, drafts, and published content |

## Guiding Philosophy

The goal of this repository is not only to collect information, but to create reusable systems that help produce consistent, secure, testable, and maintainable software.
